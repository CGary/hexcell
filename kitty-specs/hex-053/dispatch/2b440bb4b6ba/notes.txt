### 1. Pure Rust Cosine Similarity (Domain Logic)
The core vector similarity calculation has been added in the standard-only, empty-dependency crate `hexcell-core`.
* **File:** [similitud.rs](file:///home/gary/dev/hexcell/worktrees/HEX-053/crates/hexcell-core/src/similitud.rs#L19)
* **Function:** [`similitud_coseno`](file:///home/gary/dev/hexcell/worktrees/HEX-053/crates/hexcell-core/src/similitud.rs#L19)
* **Design Decision (f64 Accumulation):** Floating-point drift over 768 dimensions can easily push the cosine similarity value outside the theoretical $[-1.0, 1.0]$ bounds. To prevent this, all dot products and norms are accumulated in `f64` and clamped to `[-1.0, 1.0]` before being downcast to `f32`.
* **Edge Cases:** It returns `None` if the input vector lengths mismatch or if the magnitude of either vector is zero. Returning an `Option` is crucial because returning `0.0` or `NaN` would hide these errors, which the validator needs to act on.
* **Module Exposure:** Registered in [lib.rs](file:///home/gary/dev/hexcell/worktrees/HEX-053/crates/hexcell-core/src/lib.rs#L21) under `pub mod similitud;`.
* **Unit Tests:** Created in [similitud.rs (tests)](file:///home/gary/dev/hexcell/worktrees/HEX-053/crates/hexcell-core/tests/similitud.rs) to verify all scenarios from `AC-8` (orthogonal, identical, opposite vectors, magnitude zero, and length mismatches).

### 3. Implementing the Integrity Gate (Application Service)
The integrity validator acts as the guard before promoting a staging index to production. It runs fully offline with zero network dependencies.
* **File:** [validacion.rs](file:///home/gary/dev/hexcell/worktrees/HEX-053/crates/hexcell-storage/src/validacion.rs#L111)
* **Function:** [`validar_integridad_del_indice`](file:///home/gary/dev/hexcell/worktrees/HEX-053/crates/hexcell-storage/src/validacion.rs#L111)
* **Domain Types:** Added [`SondaResuelta`](file:///home/gary/dev/hexcell/worktrees/HEX-053/crates/hexcell-storage/src/validacion.rs#L16), [`MotivoDeRechazo`](file:///home/gary/dev/hexcell/worktrees/HEX-053/crates/hexcell-storage/src/validacion.rs#L29), and [`VeredictoDeIntegridad`](file:///home/gary/dev/hexcell/worktrees/HEX-053/crates/hexcell-storage/src/validacion.rs#L77). 
* **Design Decision (PartialEq Only):** Because `f32` floats (like thresholds and similarity scores) are carried in the payloads, we derive `PartialEq` but NOT `Eq`, `Hash`, or `Ord`, avoiding compilation failures on floating-point comparison boundaries.
* **Checks Executed (In-Order and Accumulated):**
  1. **Metadata Existence:** If `metadatos_de_epoca` is absent, we return `Ok` containing `MotivoDeRechazo::MetadatosDeEpocaAusentes` along with skip markers for subsequent checks.
  2. **Orphan Vectors:** Checks `fragmentos_sin_vector > 0` which points to ingestion-invariant bugs.
  3. **Ordinal Contiguity:** Verifies that ordinals map strictly from `0..cantidad_de_fragmentos`.
  4. **Index Emptiness:** Rejects indexes with zero fragments.
  5. **Fragmentation Coverage:** Re-runs `fragmentar` over streamed `documentos.contenido` values and compares chunk counts against the actual count in the database.
  6. **Dimensional Uniformity:** Joins tables to identify vectors where the length is not equal to `4 * dimension_de_embedding`.
  7. **Semantic Probe:** Compares a caller-supplied pre-computed vector against all fragments, keeping the best local similarity and validating it against the threshold.
* **Memory Discipline (NFR-01):** To respect the 80 MB cell memory budget, `documentos.contenido` and `vectores_de_fragmento` are streamed row-by-row using SQLite prepared statements instead of allocating vector lists in memory at once.
* **Grep Guards compliance:** The validator does not name or import `hyper`, `reqwest`, `incrustar_lote`, or any external providers, and completely delegating complex mathematics (`sqrt`, `powi`, `abs`) to the core crate, complying with the grep guard.
* **Module Exposure:** Exposed in storage's [lib.rs (storage)](file:///home/gary/dev/hexcell/worktrees/HEX-053/crates/hexcell-storage/src/lib.rs#L72).
